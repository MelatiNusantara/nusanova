# Frontend portal demo

Publikasikan isi folder ini ke site/repo Siteleaf-Jekyll **khusus demo**. Set URL API demo di `assets/demo-config.js` sebelum publikasi. URL kosong berarti API pada origin yang sama; tidak ada fallback ke API produksi.

Backend dan panduan server: `NSPK-Database/nspk-php-demo/README.md`.

Frontend tetap mengikuti aplikasi HTML/JavaScript statis sumber. Tidak memerlukan React, Node, atau Java saat disajikan. Data responden bawaan dihapus; key browser menggunakan prefix demo terpisah. Dropdown menggunakan snapshot BPS 38 provinsi / 514 kabupaten-kota, mitra menggunakan 416 baris lampiran PMO.
